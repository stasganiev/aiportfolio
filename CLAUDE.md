# Сайт ganiev.pro

Личный сайт Стаса Ганиева: Senior 1С-разработчик, автор двух курсов для 1С-разработчиков, спикер. Сайт работает как точка доверия для трёх аудиторий (1С-разработчики, компании и организаторы, зарубежные коллеги).

## Состояние

Идёт пересборка сайта по этапам. В корне пока лежит старый одностраничный сайт (`index.html`, `css/`, `js/`, `img/`): он опубликован на GitHub Pages и остаётся там до релиза новой версии. Старый код целиком сохранён тегом `v2-legacy`.

Новая версия собирается на Astro (появится на этапе 4). Данные для неё уже лежат в `src/data/`: цифры (`facts.yaml`), доклады, статьи, курсы, опыт, отзывы, контакты. Русские тексты секций до этапа 4 живут в `work/content_ru.md`. Этот раздел обновляется в конце каждого этапа.

## Как идёт работа

- Рабочий документ: `work/TZ.md`. Этапы в разделе 9, открытые вопросы в разделе 11.
- Цикл одного этапа: Стас вычитывает этап в ТЗ, согласует, затем разработка, затем приёмка.
- Делается только то, что входит в согласованный этап. Всё остальное записывается в бэклог ТЗ (раздел 12).
- Коммит только после слова «принято» от Стаса. Перед коммитом смотреть `git log`: Стас может закоммитить сам.
- Push только по просьбе Стаса. Разработка идёт прямо в `main`.
- Публикация запускается вручную (`deploy.yml`, `workflow_dispatch`). Автопубликацию по push, домен и DNS не трогать до этапа 11.
- Побочных файлов не оставлять. Заметки и черновики живут только в `work/`.

## Правила контента

- Источник фактов о Стасе: `C:\AI_dev\claude\about_me\` и резюме в `C:\AI_dev\claude\results\career\`. Курсы: `C:\AI_dev\work_AI_arsenal_1C\` и `C:\AI_dev\claude\projects\course_git\`.
- Утверждённые цифры: 18 докладов, 13 статей, 55 выпускников двух курсов. На новой версии любая цифра берётся из `src/data/facts.yaml`, руками в тексты не пишется.
- Нельзя: «ищу работу», «открыт к предложениям», «junior», учебные проекты HTML Academy под видом фриланса, имена детей, внутренние детали проектов SOFTSWISS сверх резюме.
- Стиль текстов: `C:\AI_dev\claude\anti_ai_style.md`.

## Языки

Три полных языка: английский по умолчанию (`/`), русский (`/ru/`), сербский латиницей (`/sr/`). Русский текст пишется первым и служит мастер-версией. Правка текста вносится во все три языка одним коммитом.

## Приватность

- `work/` в `.gitignore`: там аудит, ТЗ и личные заметки. Репозиторий публичный, в него это попадать не должно.
- Личные адреса и телефоны в код не писать. Получатель писем из формы задаётся в шаблоне EmailJS, а не в коде.

## Окружение

- Windows 11, Node 24, npm 11.
- Python запускать через `python`, не `python3`.
- Скриншоты для проверки: Chrome в режиме `--headless=new --screenshot`.

## Скиллы проекта

Лежат в `.claude/skills/`:

- `design-system`: токены и спецификации компонентов.
- `design`: логотип, иконки, баннеры. Генерация картинок требует ключ Gemini API.
- `stop-slop`: проверка текстов на признаки машинного письма. Через него проходят все тексты сайта.
- `ui-ux-pro-max`: чек-лист качества интерфейса. Поисковый движок (`scripts/`, `data/`) не установлен, команды поиска из его инструкции не работают.

В инструкциях скиллов пути указаны как `~/.claude/skills/...` и `python3`. В этом проекте скрипты лежат в `.claude/skills/<имя>/scripts/` и запускаются через `python`.
